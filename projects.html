Past Projects

Below is a list and description of my past projects and contributions.

Project 1: Network Configuration

Last semester, I worked on configuring an enterprise network using Cisco Packet Tracer. Our objective was to design and deploy a complex topology incorporating vlan segmentation, and static routing using our student ID's.

Project 2: Kali Linux Security Demo

This semester, my team and I developed a security demonstration project using Kali Linux. We mirrored and simulated a clone of the Ontario Tech Website to understand modern attack techniques hackers use today.

Project 3: Student Grade Management Application

My team developed a student grade management system designed to calculate weighted averages based on customizable course grading schemes. The program supported complex manipulation of data, allowing the user to add, filter, sort and remove student profiles using unique ID's.

Project 4: GUI Calculator in Python

I built a multi-mode calculator with a Graphical User Interface using Python and Tkinter. The application featured different screens for the different operation modes of the calculator.

Project 5: Filesystem Understanding Project

I designed a Python-based file management application featuring a Graphical User Interface for navigation and it was written using native Python file handling methods.
